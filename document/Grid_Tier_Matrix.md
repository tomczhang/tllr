# 📊 档位分级矩阵 (Grid Tier Matrix)

## 概述

档位分级矩阵是贪婪猎人策略的核心风控机制，根据**市值规模**和**历史回撤**动态调整金字塔网格的**加仓间隔**，实现风险与收益的平衡。

---

## 🎯 四大档位

| 档位名称 | 判定标准 | 加仓间隔 | 6发覆盖深度 | 典型标的 |
|---------|---------|---------|------------|---------|
| **稳健档 (Robust)** | 白名单（宽基指数/顶级控股） | 4.0% | -22% | SPY, QQQ, BRK.B |
| **标准档 (Standard)** | 市值 > 2000亿USD 且 最大回撤 < 50% | 7.5% | -37% | AAPL, MSFT, GOOGL, UNH |
| **激进档 (Aggressive)** | 市值 > 2000亿USD 且 最大回撤 ≥ 50% | 10.0% | -47% | META, AMZN, NVDA, 0700.HK |
| **魔鬼档 (Devil)** | 市值 < 2000亿USD（一票否决） | 15.0% | -62% | TSLA, 9992.HK, 大部分成长股 |

---

## 🔍 判定逻辑

### 决策树

```
开始
  ↓
是否在白名单？
  ├─ 是 → 稳健档 (4.0%)
  └─ 否 → 检查市值
            ↓
         市值 < 2000亿USD？
            ├─ 是 → 魔鬼档 (15.0%)
            └─ 否 → 检查回撤
                      ↓
                   最大回撤 < 50%？
                      ├─ 是 → 标准档 (7.5%)
                      └─ 否 → 激进档 (10.0%)
```

### 代码实现

```python
def _determine_grid_tier(symbol, market_cap, max_drawdown):
    # 白名单：稳健档
    if symbol in ["SPY", "QQQ", "VOO", "BRK.B"]:
        return ("稳健档", 0.04, "宽基指数/顶级控股")
    
    # 市值阈值：2000亿美元 = 2e11
    if market_cap < 2e11:
        return ("魔鬼档", 0.15, "小市值/高风险")
    
    # 大市值，根据回撤判断
    if abs(max_drawdown) < 0.50:
        return ("标准档", 0.075, "大市值/低回撤")
    else:
        return ("激进档", 0.10, "大市值/高回撤")
```

## 📐 金字塔网格计算

### 6发子弹分配

| 层级 | 资金占比 | 描述 |
|------|---------|------|
| 第1步 | 5% | 试探性建仓 |
| 第2步 | 10% | 确认趋势 |
| 第3步 | 15% | 加大仓位 |
| 第4步 | 25% | 重仓布局 |
| 第5步 | 25% | 极度低估 |
| 第6步 | 20% | 底部抄底 |
| **合计** | **100%** | 全部仓位 |

### 价格计算公式

```
第1步价格 = 安全价
第2步价格 = 第1步价格 × (1 - 加仓间隔)
第3步价格 = 第2步价格 × (1 - 加仓间隔)
...
第N步价格 = 第(N-1)步价格 × (1 - 加仓间隔)
```

### 档位示例对比

假设安全价 = $100

| 层级 | 稳健档 (4%) | 标准档 (7.5%) | 激进档 (10%) | 魔鬼档 (15%) |
|------|-------------|--------------|-------------|-------------|
| 第1步 | $100.00 | $100.00 | $100.00 | $100.00 |
| 第2步 | $96.00 | $92.50 | $90.00 | $85.00 |
| 第3步 | $92.16 | $85.56 | $81.00 | $72.25 |
| 第4步 | $88.47 | $79.14 | $72.90 | $61.41 |
| 第5步 | $84.93 | $73.21 | $65.61 | $52.20 |
| 第6步 | $81.53 | $67.72 | $59.05 | $44.37 |
| **覆盖深度** | **-18.5%** | **-32.3%** | **-40.9%** | **-55.6%** |

## 🔄 货币转换规则

### 市值统一标准

所有市值统一转换为**美元(USD)**进行判定：

| 原始货币 | 转换方式 | 示例 |
|---------|---------|------|
| **USD** | 无需转换 | $4,029B → 40,290亿USD |
| **HKD** | 实时汇率 × 1 HKD (约0.128 USD) | 5.53万亿HKD → 7,072亿USD |
| **CNY** | 实时汇率 × 1 CNY (约0.138 USD) | 2.5万亿CNY → 3,450亿USD |
| **CNH** | 离岸汇率 | 同CNY |

### 汇率更新机制

- **数据源**: Yahoo Finance API
- **缓存时长**: 1小时
- **备用汇率**: 
  - HKD: 0.128 USD
  - CNY: 0.138 USD
- **刷新策略**: 自动刷新，失败时使用备用汇率

## 📈 档位设计理念

### 1. 稳健档 (4%) - 守护资产

**设计目标**: 最小化波动，稳健增值

**适用标的**:
- 宽基指数 (SPY, QQQ, VOO)
- 伯克希尔 (BRK.B)

**核心特点**:
- 最窄间隔，频繁加仓
- 6发覆盖深度-22%
- 适合长期核心仓位

---

### 2. 标准档 (7.5%) - 价值投资

**设计目标**: 平衡风险与收益

**适用标的**:
- 超大市值蓝筹 (AAPL, MSFT, GOOGL)
- 回撤<50%的稳健股

**核心特点**:
- 中等间隔，兼顾安全与收益
- 6发覆盖深度-37%
- 最常见的配置档位

---

### 3. 激进档 (10%) - 高波动容忍

**设计目标**: 应对大市值高波动股

**适用标的**:
- 大市值科技股 (META, NVDA, AMZN)
- 港股龙头 (0700.HK)

**核心特点**:
- 较宽间隔，深度覆盖
- 6发覆盖深度-47%
- 需要较强承受能力

---

### 4. 魔鬼档 (15%) - 极限挑战

**设计目标**: 应对极端波动

**适用标的**:
- 中小市值成长股
- 高波动周期股
- 大部分中概股

**核心特点**:
- 最宽间隔，极深覆盖
- 6发覆盖深度-62%
- 高风险高收益，谨慎使用

## ⚠️ 风险提示

### 1. 市值门槛的意义

**为什么2000亿？**
- 代表企业进入成熟期
- 抗风险能力显著提升
- 流动性充足
- 不易被操纵

### 2. 回撤的参考价值

**近10年最大回撤**反映:
- 历史波动特征
- 极端情况下的跌幅
- 投资者需要的心理承受能力

### 3. 档位不是评级

**重要区分**:
- 档位 ≠ 质量评分
- 魔鬼档 ≠ 垃圾股
- 例如: TSLA虽在魔鬼档，但可能是优质成长股

## 🛠️ 实现细节

### 技术架构

```
用户输入(股票代码)
    ↓
后端获取数据
    ├─ 市值 (自动转USD)
    ├─ 近10年历史数据
    └─ 最大回撤计算
    ↓
档位判定逻辑
    ├─ 检查白名单
    ├─ 判断市值阈值
    └─ 判断回撤水平
    ↓
生成金字塔网格
    ├─ 计算各层价格
    ├─ 分配资金比例
    └─ 判断触发状态
    ↓
前端展示策略表格
```

### 核心代码路径

- **后端判定逻辑**: `backend/app/services/calculator_v2.py`
  - `_determine_grid_tier()` - 档位判定
  - `_generate_pyramid_strategy()` - 策略生成

- **货币转换**: `backend/app/services/currency_converter.py`
  - `convert_to_usd()` - USD转换

- **前端展示**: `frontend/src/pages/CalculatorPage.tsx`
  - 金字塔网格表格渲染

## 📊 使用建议

### 1. 组合配置

**均衡组合示例**:
```
稳健档: 40% (指数基金)
标准档: 40% (大市值蓝筹)
激进档: 15% (科技龙头)
魔鬼档: 5%  (成长股)
```

### 2. 仓位管理

- **稳健档**: 可满仓使用全部6发
- **标准档**: 建议使用4-5发
- **激进档**: 建议使用3-4发
- **魔鬼档**: 建议使用1-2发

### 3. 监控要点

- 定期复核市值变化
- 关注重大回撤事件
- 及时调整档位分类
