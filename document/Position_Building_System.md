## 核心定价模型：三因子系统

### 公式

```
安全建仓价 = 内在价值估算 × 公司质量折扣系数 × 市场折扣系数
```

### 设计原理

这个三因子模型的核心思想是：**通过多重安全边际的叠加，确保即使在单一因子判断失误的情况下，整体仍然保持足够的安全空间**。

```
原始估值: $100
      ↓
× 质量系数 (0.50-0.95)  ← 第一层安全边际（公司质量）
      ↓
× 市场系数 (0.70-1.0)   ← 第二层安全边际（市场流动性）
      ↓
最终安全价: $33.25 - $95.00
```

每一层折扣都是对风险的量化定价，确保投资者支付的价格显著低于公司的内在价值。

## 第一因子：内在价值估算

### 定义
内在价值是用户对公司长期价值的主观判断，基于对公司业务、竞争力、增长潜力的深度研究。

### 估算方法

1. **DCF折现法**
   - 预测未来5-10年的自由现金流
   - 使用合理的折现率（通常8-12%）
   - 计算终值（Terminal Value）

2. **相对估值法**
   - 对比同行业优质公司的P/E、P/B倍数
   - 考虑公司的增长率和ROE差异
   - 给出合理估值区间

3. **分部估值法**
   - 将不同业务线分别估值
   - 适用于多元化经营的公司
   - 汇总得出整体价值

### 关键原则

- **保守原则**: 宁可低估，不可高估
- **长期视角**: 着眼于3-5年的价值创造能力
- **场景分析**: 考虑乐观、中性、悲观三种情况

### 示例

```
Apple (AAPL) 估值示例:
- DCF估值: $185 (基于10%增长率，10%折现率)
- 相对估值: $195 (25倍P/E，基于7.8美元EPS)
- 最终采用: $180 (保守起见，取较低值)
```

## 第二因子：公司质量折扣系数（8点评分体系）

### 系统架构

8点评分体系分为两大类：
- **完全自动化（4项）**: 基于API数据自动计算
- **完全人工判断（4项）**: 需要用户基于研究做出判断

### 评分细则

#### 📊 完全自动化指标（4项）

| 指标 | 阈值 | 得分条件 | 数据来源 |
|-----|------|---------|---------|
| **市值规模** | ≥ 2000亿美元 | 市值达标得1分 | Yahoo Finance API |
| **上市年限** | ≥ 10年 | 上市满10年得1分 | Yahoo Finance API |
| **毛利率** | ≥ 40% | 毛利率达标得1分 | Yahoo Finance API |
| **净资产收益率(ROE)** | ≥ 15% | ROE达标得1分 | Yahoo Finance API |

**设计意图**:
- **市值规模**: 大市值公司抗风险能力强，流动性好
- **上市年限**: 经过完整经济周期考验，商业模式成熟
- **毛利率**: 反映定价权和竞争优势
- **ROE**: 衡量资本使用效率和盈利能力

#### 🧠 完全人工判断指标（4项）

| 指标 | 判断标准 | 得分条件 | 考察维度 |
|-----|---------|---------|---------|
| **财务安全** | 现金 > 负债 | 用户确认得1分 | 现金充裕度、债务风险 |
| **股东回报** | 分红率>1% 或 回购额>10亿 | 用户确认得1分 | 分红政策、股票回购 |
| **行业地位** | Top 3或品类第一 | 用户确认得1分 | 市场份额、品牌影响力 |
| **护城河** | 深度护城河 | 用户确认得1分 | 网络效应、规模经济、品牌、专利 |

**设计意图**:
- **财务安全**: 确保公司有足够现金应对危机
- **股东回报**: 管理层对股东友好度
- **行业地位**: 垄断地位或寡头地位
- **护城河**: 长期竞争优势的可持续性

### 评级映射与质量系数

| 总分 | 评级 | 描述 | 质量系数 | 特征 |
|-----|------|------|---------|------|
| 7-8分 | S级 | 皇冠明珠 | **0.95** | 全方位优质，极低风险 |
| 5-6分 | A级 | 优质蓝筹 | **0.85** | 整体优秀，风险可控 |
| 3-4分 | B级 | 平庸/成长 | **0.70** | 存在瑕疵或处于成长期 |
| 0-2分 | C级 | 垃圾/高危 | **0.50** | 高风险，需极大安全边际 |

### 质量系数的经济学意义

质量系数本质上是对**估值不确定性的折扣**：

- **S级公司 (0.95)**: 95%的确定性，5%的安全边际
- **A级公司 (0.85)**: 85%的确定性，15%的安全边际
- **B级公司 (0.70)**: 70%的确定性，30%的安全边际
- **C级公司 (0.50)**: 50%的确定性，50%的安全边际

**示例**:
```
内在价值估算: $100

S级公司: $100 × 0.95 = $95 (只要5%折扣)
A级公司: $100 × 0.85 = $85 (需要15%折扣)
B级公司: $100 × 0.70 = $70 (需要30%折扣)
C级公司: $100 × 0.50 = $50 (需要50%折扣)
```

## 第三因子：市场折扣系数

### 市场分级

| 市场 | 折扣系数 | 理由 | 典型特征 |
|-----|---------|------|---------|
| **美股 (US)** | 1.0 | 全球流动性最好的市场 | 无涨跌停限制、T+0、深度好 |
| **A股 (A)** | 0.85 | 流动性较好，有交易限制 | 10%涨跌停、T+1、监管严格 |
| **港股 (HK)** | 0.70 | 流动性较差，折扣较大 | 老千股风险、退市风险、流动性差 |

### 特殊豁免规则

**港股S级豁免**:
- **条件**: 市值 > 2000亿美元 且 近10年最大回撤 < 50%
- **效果**: 折扣系数从 0.70 → 0.85
- **理由**: 超大型优质港股（如腾讯）流动性与A股相当

### 市场折扣的风险来源

1. **流动性风险**
   - 买卖价差
   - 大额交易的冲击成本
   - 紧急情况下的变现难度

2. **制度风险**
   - 涨跌停限制
   - T+1结算制度
   - 监管政策变化

3. **信息风险**
   - 信息披露质量
   - 财务造假风险
   - 公司治理问题

### 折扣叠加效果

```
港股C级公司:
$100 × 0.50(质量) × 0.70(市场) = $35 (65%折扣)

美股S级公司:
$100 × 0.95(质量) × 1.0(市场) = $95 (5%折扣)

两者安全边际相差: 65% - 5% = 60%
```

这就是为什么**选对公司比选对价格更重要**！

## 金字塔网格策略：动态建仓执行

### 核心理念

**在不确定的市场中，通过分批建仓来应对不确定性，越跌越买，摊薄成本。**

### 动态档位分级矩阵

系统根据**市值规模**和**最大回撤**两个维度，自动判定建仓策略档位：

| 档位 | 判定标准 | 加仓间隔 | 6发覆盖深度 | 典型标的 |
|-----|---------|---------|------------|---------|
| **稳健策略** | 手动白名单（宽基指数/顶级控股） | 4% | -22% | SPY, QQQ, BRK.B |
| **标准策略** | 市值>2000亿 且 回撤<50% | 7.5% | -37% | AAPL, MSFT, GOOGL |
| **波动策略** | 市值>2000亿 且 回撤≥50% | 10% | -47% | META, AMZN, NVDA |
| **魔鬼策略** | 市值<2000亿（一票否决） | 15% | -62% | 小市值/成长股 |

### 档位判定逻辑

```python
if 在白名单中:
    return "稳健策略", 4%
    
if 市值 < 2000亿美元:
    return "魔鬼策略", 15%  # 一票否决
    
if 最大回撤 < 50%:
    return "标准策略", 7.5%
else:
    return "波动策略", 10%
```

### 金字塔资金分配

**6步建仓，1:1:1.5:2:2:2.5 份数比例（共10份）**

| 步数 | 份数占比 | 建议说明 | 心理状态 |
|-----|---------|---------|---------|
| 第1步 | 10% (1份) | 试探性建仓 | 观察市场反应 |
| 第2步 | 10% (1份) | 确认趋势 | 验证判断 |
| 第3步 | 15% (1.5份) | 加大仓位 | 建立信心 |
| 第4步 | 20% (2份) | 重仓布局 | 坚定持有 |
| 第5步 | 20% (2份) | 极度低估 | 贪婪时刻 |
| 第6步 | 25% (2.5份) | 底部抄底 | All in |

### 建仓策略示例

**Apple (AAPL) - 标准策略 (7.5%间隔)**

```
安全建仓价: $180.00
当前价格: $219.85
档位: 标准策略 (市值39513亿USD > 2000亿, 最大回撤38.7% < 50%)

网格价格    跌幅     买入份数    累计仓位    战术指标
--------  -------  ---------  ----------  ----------------------------------
$180.00   基准价    1.0 (10%)    10%       累计回撤: -0.0% • 成本拉低: -0.0%
$166.50   -7.5%    1.0 (10%)    20%       累计回撤: -7.5% • 成本拉低: -3.8%
$154.01   -7.5%    1.5 (15%)    35%       累计回撤: -14.4% • 成本拉低: -8.8%
$142.46   -7.5%    2.0 (20%)    55%       累计回撤: -20.9% • 成本拉低: -14.6%
$131.77   -7.5%    2.0 (20%)    75%       累计回撤: -26.8% • 成本拉低: -20.6%
$121.89   -7.5%    2.5 (25%)   100%       累计回撤: -32.3% • 成本拉低: -26.8%
```

### 战术指标解读

每一步建仓都计算三个关键指标：

1. **累计回撤**: 当前价格相对安全建仓价的跌幅
2. **成本拉低**: 平均成本相对安全建仓价的降低幅度
3. **回本所需反弹**: 从当前价格涨回平均成本所需的涨幅

**示例（第3步）**:
```
当前价格: $154.01 (跌14.4%)
平均成本: $164.25 (低于基准价8.8%)
回本所需: +6.6% (从$154.01涨到$164.25)
```

### 策略优势

1. **降低择时压力**: 不需要判断最低点，只需判断合理区间
2. **摊薄成本**: 越跌越买，平均成本显著低于安全建仓价
3. **心理优势**: 按计划行动，避免情绪化决策
4. **资金管理**: 预留足够子弹应对更大跌幅

## 技术分析辅助：左右侧判断

### 均线系统

**MA50（50日均线）和 MA200（200日均线）**

```
右侧交易时刻 (价格 > MA50 且 > MA200):
  → 价格未站稳均线，请甘愿踏空，放弃抄底的执念
  → 趋势确认后，请带好止损果断上车

左侧交易时刻 (价格 < MA50 或 < MA200):
  → 价格在均线下方，请务必管住手
  → 严格执行您的网格，不要在没有信号时随意加仓
```

### 最大回撤分析（近10年）

| 回撤幅度 | 波动性评估 | 建议 |
|---------|-----------|------|
| > 50% | 高波动股票 | 仓位控制，心理准备 |
| 30%-50% | 中等波动 | 标准仓位 |
| < 30% | 低波动 | 可适当提高仓位 |

**回撤的意义**:
- 衡量公司历史极端风险
- 评估投资者需要承受的心理压力
- 决定金字塔策略的建仓间隔

### 120日前高警示

**阈值**: 距120日前高跌幅 < 15%

**触发警告**:
```
⚠️ 重要风险提示：距120日前高仅跌7.4%
120日前高：$237.49 (2024-11-15)
不符合首仓安全阈值（需跌幅≥15%）。
建议谨慎思考，等待更大回撤空间，避免追高风险。
```

**设计原理**:
- 防止在相对高位开始建仓
- 120日（约6个月）是一个合理的前高周期
- 15%是一个足够的回撤安全缓冲

## 风险提示机制

### 多层风险识别

1. **估值风险**
   ```
   当前价格 > 安全建仓价 + 10%
   → "❌ 当前价格高于安全价XX%，等待回调"
   ```

2. **波动风险**
   ```
   近10年最大回撤 > 50%
   → "⚠️ 历史最大回撤XX%，极端风险"
   ```

3. **追高风险**
   ```
   距120日前高 < 15%
   → "⚠️ 距120日前高仅跌X%，不符合首仓安全阈值"
   ```

4. **质量风险**
   ```
   公司质量评分 < 3分
   → "C级 (垃圾/高危)" + 50%质量折扣
   ```

5. **市场风险**
   ```
   港股 + 非S级
   → 0.70市场折扣（相当于30%安全边际）
   ```

### 风险管理原则

**多重安全边际叠加**:
```
最终安全边际 = 质量折扣 + 市场折扣 + 价格折扣

示例（港股B级公司，当前价格比安全价低20%）:
= (1 - 0.70)质量折扣
+ (1 - 0.70)市场折扣  
+ 20%价格折扣
= 30% + 30% + 20% = 80% 总安全边际
```

## 为什么这套系统有效？

### 1. 多维度风险定价

**传统投资方法的问题**: 
- 单一维度判断（只看估值或只看技术面）
- 缺乏系统化风险量化
- 依赖主观判断和运气

**本系统的优势**:
```
风险维度            量化方式              安全边际
-----------        -----------          -----------
公司质量风险  →  质量折扣系数(0.50-0.95)  →  5%-50%
市场流动性风险 → 市场折扣系数(0.70-1.0)   →  0%-30%
估值风险     →  安全建仓价 vs 当前价    →  可变
波动风险     →  金字塔档位调整(4%-15%)  →  动态适应
```

**风险叠加效应**:
即使在单一维度判断失误，其他维度的安全边际仍能提供保护。

### 2. 克服人性弱点

| 人性弱点 | 表现 | 系统对策 |
|---------|------|---------|
| **贪婪** | 追涨杀跌，追高买入 | 120日前高警示 + 安全价门槛 |
| **恐惧** | 暴跌时不敢买入 | 金字塔策略机械化执行 |
| **锚定效应** | 固守买入成本 | 战术指标动态显示实际成本 |
| **确认偏误** | 只看利好消息 | 8点质量评分强制全面审视 |
| **过度自信** | 重仓单一股票 | 分批建仓 + 仓位管理 |

### 3. 概率思维与期望值管理

**赌场思维 vs 投资思维**:

```
赌场思维: 
"这次一定能抓住最低点！"
期望值 = 5% × 50倍收益 - 95% × 全部本金 = 负

投资思维:
"我按系统建仓，不奢望抓最低点"
期望值 = 60% × 2倍收益 + 40% × (-20%亏损) = +112%
```

**系统的概率优势**:
1. 通过三因子折扣，确保买入价格大概率低估
2. 通过金字塔策略，增加"买到更低价"的概率
3. 通过分散时间建仓，降低"一次性买在最高点"的概率

### 4. 长期复利效应

**单次投资的运气成分**: 高
**系统化投资的长期回报**: 可预期

```
假设10次投资机会:
• 7次成功（翻倍）: 7 × 100% = +700%
• 2次平庸（+20%）: 2 × 20% = +40%
• 1次失败（-20%）: 1 × (-20%) = -20%

平均每次: (+700% + 40% - 20%) / 10 = +72%
```

**关键**: 
- 降低失败概率（三因子定价）
- 控制失败损失（安全边际 + 止损）
- 提高成功率（质量筛选 + 价格纪律）

### 5. 系统化 vs 情绪化

**情绪化投资的典型路径**:
```
看新闻兴奋 → 追高买入 → 市场回调 → 恐慌割肉 → 踏空反弹 → 懊悔再追 → 循环往复
```

**系统化投资的标准路径**:
```
设定标准 → 等待机会 → 达到安全价 → 执行网格 → 机械建仓 → 耐心持有 → 达到目标位卖出
```

### 6. 真实案例分析

#### 案例1: Apple (AAPL) - 标准策略

```
时间: 2024年11月
内在价值估算: $200
公司质量: 7分 (S级, 0.95系数)
市场: 美股 (1.0系数)

安全建仓价: $200 × 0.95 × 1.0 = $190
当前价格: $219.85
判断: 当前价格高于安全价15.7%，等待回调

策略: 等待价格跌至$190以下开始执行7.5%间隔金字塔策略
预期: 6发子弹打完，平均成本约$164 (相比$190低13.7%)
```

#### 案例2: Meta (META) - 波动策略

```
时间: 2024年11月
内在价值估算: $350
公司质量: 6分 (A级, 0.85系数)
市场: 美股 (1.0系数)
最大回撤: 76.7% (2018-2022)

安全建仓价: $350 × 0.85 × 1.0 = $297.50
当前价格: $580
判断: 当前价格高于安全价95%，极度高估

策略: 
1. 由于最大回撤>50%，判定为"波动策略"
2. 采用10%建仓间隔（比标准7.5%更保守）
3. 等待价格跌至$297.50以下开始建仓
4. 预留更多资金应对可能的大幅波动

教训: 
高波动股票需要更大安全边际和更宽的建仓间隔
```

### 7. 系统的局限性

**诚实面对**:

1. **不能预测短期走势**
   - 系统不是水晶球
   - 无法判断明天涨跌
   - 适合中长期投资（1-3年）

2. **需要耐心等待**
   - 大多数时候没有机会
   - 需要等待市场恐慌
   - 可能错过快速反弹

3. **依赖内在价值判断**
   - 如果内在价值估算错误，整个系统失效
   - 需要用户具备基本的估值能力
   - 建议采用保守估值

4. **不适用于所有类型公司**
   - 不适合亏损公司
   - 不适合商业模式未验证的公司
   - 不适合周期性极强的公司

5. **市场可能长期非理性**
   - 好公司可能长期被低估
   - 需要足够的资金和心理准备
   - 可能需要2-3年才看到回报

## 总结：系统的核心价值

### 三个核心支柱

```
1. 定价支柱（三因子模型）
   → 确保买入价格具有足够安全边际
   
2. 执行支柱（金字塔策略）
   → 确保建仓过程纪律化、机械化
   
3. 风控支柱（多重风险提示）
   → 确保不犯致命错误
```

### 投资哲学

> **"Be fearful when others are greedy, and greedy when others are fearful."**
> — Warren Buffett

贪婪猎人系统就是这一理念的量化和系统化：

1. **在市场贪婪时**（价格 > 安全价）
   - 系统明确提示"等待回调"
   - 不参与追涨
   - 保持现金耐心等待

2. **在市场恐惧时**（价格 < 安全价）
   - 系统提示"贪婪时刻"
   - 按网格机械化买入
   - 越跌越买，摊薄成本

### 最终目标

**不是追求一次性抓住最低点，而是通过系统化方法：**

1. ✅ 提高胜率（买在合理估值区间）
2. ✅ 控制赔率（多重安全边际保护）
3. ✅ 克服人性（机械化执行，避免情绪干扰）
4. ✅ 长期复利（重复应用，持续获利）

## 使用指南

### 新手建议

1. **从大市值蓝筹开始**
   - 选择S级或A级公司
   - 市值 > 5000亿美元
   - 上市 > 15年

2. **采用保守估值**
   - DCF估值打8折
   - 相对估值取行业平均P/E的80%
   - 宁可错过，不要买贵

3. **严格执行网格**
   - 提前设定每一步的买入价格
   - 不提前加仓，不跳过步骤
   - 保留最后两发子弹应对极端情况

### 进阶策略

1. **动态调整内在价值**
   - 每季度财报后重新评估
   - 如果基本面恶化，调低估值
   - 如果超预期增长，适当调高

2. **组合管理**
   - 不超过5-8只股票
   - 每只初始仓位不超过15%
   - 行业分散，避免集中风险

3. **退出策略**
   - 价格达到内在价值的120%时考虑减仓
   - 公司质量评分降至B级以下时警惕
   - 发现更好机会时可以置换
